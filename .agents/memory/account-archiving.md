Account cleanup is archive-only; never permanently delete accounts.

**Why:** The user explicitly chose "Archive accounts only; never permanently delete" when asked how deletion should handle logged hours.

**How to apply:** Preserve profiles, hours, messages and audit history. Hide archived accounts from normal directories and new message audiences, not historical reports. Archive through deactivation safeguards; restore visibility without silently reactivating access or resurrecting shifts.
