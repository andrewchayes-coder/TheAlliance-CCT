We're building the "Alliance Volunteer Portal," a standalone volunteer management web app for The Alliance's Resource Coordination Program. Volunteers sign up, get verified and approved by Alliance staff, then sign up for recurring 2-hour phone shifts (Mon–Fri). Admins manage volunteers, the master schedule, messaging, and a small resource hub. Pilot: 12–15 volunteers in Placer County, growing to ~60 across 5 counties. It must work very well on phones.

In this first step, set up the project skeleton and the brand design system only. Don't build features yet.

STACK
- React + Vite + TypeScript, Tailwind CSS, shadcn/ui components, wouter for routing, TanStack Query for data fetching
- Express + TypeScript backend
- Replit-managed PostgreSQL with Drizzle ORM (schema in shared/schema.ts)
- Folder layout: client/, server/, shared/
- All dates/times are handled in America/Los_Angeles. Store timestamps in UTC; display in Pacific.

APP CONFIG
Create shared/appConfig.ts exporting: appName ("Alliance Volunteer Portal"), orgName ("The Alliance"), timezone ("America/Los_Angeles"), defaultCounty ("Placer"), counties (["Placer","Sacramento","Nevada","El Dorado","Sutter"] — placeholder), maxShiftsPerVolunteer (2), minShiftsPerVolunteer (1), reminderHoursBefore (24), sameMorningReminder (false), sameMorningReminderHour (7). Every other part of the app reads from this file.

BRAND SYSTEM (follow exactly)
Colors — define as CSS variables and Tailwind theme colors:
- navy  #06365D  (primary: headers, body text, navigation)
- teal  #02928F  (subheaders, accents, CTAs, links)
- gray  #E6E6E6  (form fields, subtle backgrounds, borders)
- white #FFFFFF
- teal-text #027A77 (use ONLY for small teal text on white, for accessible contrast)
- navy-soft: navy at 60% opacity (placeholder text)
Target visual ratio: roughly 60% navy / 25% white / 10% light gray / 5% teal. Teal is reserved for actions and labels, never large fills.

Typography:
- Load Open Sans (400, 600, 700) from Google Fonts.
- Display font "Lulo Clean": add an @font-face that loads /public/fonts/LuloClean.woff2 if it exists; fallback stack "Lulo Clean", "Montserrat", sans-serif (load Montserrat 800 from Google Fonts). Display text is always uppercase with 0.06em letter-spacing.
- h1 / page titles: display font, 28px, navy, uppercase (scale to 22px on mobile)
- Subheaders and field labels: Open Sans Bold, 15px, teal-text, uppercase, 0.04em letter-spacing (e.g., "COUNTY", "BACKGROUND CHECK", "UPCOMING SHIFTS")
- Body: Open Sans Regular, 17px, navy, line-height 1.55
- Inputs: Open Sans 15px, navy text on gray (#E6E6E6) background, no border, 8px radius, focus state = 2px teal ring; placeholder navy-soft

Components — create themed shadcn variants:
- Primary button: teal background, white Open Sans Bold 15px uppercase text, 8px radius; hover darkens to navy
- Secondary button: white background, 1.5px teal border, teal text; hover = teal background, white text
- Card: white, 12–16px radius, subtle shadow, generous padding (24px desktop / 16px mobile), consistent spacing between cards
- Status badge component (we'll use it for volunteer status, background check, certification): pill shape; neutral states use gray bg + navy text; "good" states use teal bg + white text; "attention" states use a soft amber; "blocked" states use a soft red. Keep it calm, not alarming.
- Empty-state component: short warm message + optional CTA

Layouts:
- PublicLayout (sign-in/sign-up): centered card on a white page with a navy top band holding the wordmark
- AppLayout: navy top bar with the app name/logo (logo from /public/brand/logo.svg if present, otherwise the text wordmark in the display font, white), a nav, and a user menu. On mobile, the nav collapses to a bottom tab bar (volunteers) or a hamburger sheet (admins).
- Generous white space, uncluttered, clear hierarchy. Rounded, soft cards. The tone is compassionate, trustworthy, local, clear, hopeful — never corporate or clinical.
